# agents/ — AI 编程工具共享参考

本目录是**唯一被 git 跟踪**的 AI 编程辅助资料目录，供 ZCode、Claude Code、
WorkBuddy 等各类 AI 编程工具与人类协作者共用。各工具的私有记忆目录
（`.zcode/`、`.claude/` 等）默认不入库；需要跨工具、跨会话沉淀的项目级
经验记录在此。

## 维护规则

- 只收录**项目级**内容：已发生问题的根因、经验证的操作方法、技术选型背景。
  通用编程常识不收录；**个人开发机的环境配置与资源差异**（有无
  docker/MySQL、代理、算力等）不收录，属个人环境范畴。实现细节归代码
  注释；工程约定（如何修改代码）归根目录 `AGENTS.md`。本目录的定位是
  「**事后总结的教训**」——工程约定规定正确做法，教训记录错误成因。
- **保持更新**：过时内容删除，项目经验保留；每次问题核实后追加一条，
  一条对应一个根因，不复述事故过程。
- AI 生成的分析/评审报告默认**不入库**；确有沉淀价值的，提炼成条目
  写入 `lessons.md`，原文件丢弃。
